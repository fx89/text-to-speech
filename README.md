# text-to-speech
PTTS wrapper script that generates dialogues using multiple voices and models, optionally stitching the generated sounds together using Pydub. 

## References:

### PTTS
This script relies on Gradium AI's PTTS for voice generation. See more details at [the project's GitHub page](https://github.com/gradium-ai/xn-ptts). 

### PyDub
This script uses PyDub to stitch together audio files generated by PTTS. See more details at [the project's GitHub page](https://github.com/jiaaro/pydub/).

### Phonon 31m
The Phonon 31m model and names of voices provided by this model are referenced in the example that comes with this script, as well as in this readme file. This model can be used under the Apache 2.0 license and can be downloaded free of charge from [Hugging Face](https://huggingface.co/gradium/phonon-31m-en). 

## Installing

### Virtual environment
To avoid dependency conflicts, it is recommended to set up a new virtual environment for the script. For example:
```
python -m venv /path/to/new/virtual/environment
```

### Building
If not already installed, install the build frontend
```
pip install build
```

Build the package (generates sdist and wheel in dist/)
```
python -m build
```

Alternatively, one may install the package in editable mode
```
python -m pip install -e .
```

### Listing available voices
The following command can be used to list the voices available in a given model. This just wraps over the --list-voices functionality of PTTS.
```
text-to-speech.py [-m <model-path>] --list-voices
```
